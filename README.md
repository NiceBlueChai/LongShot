# LongShot

Windows 截图工具：普通截图优先、托盘常驻、完成默认复制，支持单屏框选、直接标注与向下长截图。
使用 C++14、Qt 5.12.9 Widgets、Win32 和 CMake。路线图与验收记录见 [TODO.md](TODO.md)。

## 快速使用

1. 启动 `dist\LongShot.exe`，单击托盘图标或使用设置中的截图快捷键。
2. 鼠标悬停自动预选窗口或控件；滚轮向上选父级、向下选子级。单击确认选区；直接拖动可手工框选。预选时 Tab 切换自动／手工模式。
3. 确认后直接拖动蓝框四边、四角调整尺寸，选择“选区”工具可在框内拖动移动。边框有八个圆形控制点，标签显示物理像素尺寸；光标随调整方向变化。
4. 框选后直接选择矩形、箭头、文字或马赛克，在选区内标注，无需点击“编辑”。撤销／重做可回退操作；“完成”复制并收起，“保存”导出 PNG 后可继续标注。
5. 需要长图时点“长截图”，按下文选择绿色滚动区域，再点“开始”。

每次选区限定在一块显示器内，可以在任意显示器上开始框选并覆盖该屏内的多个窗口；不支持跨屏拖选。普通手工选区最小 2×2 逻辑像素。
普通截图使用启动截图时所在显示器的底图，预览、标注、复制与保存使用同一画面。拖动边框可以直接缩小截图范围；标注固定在画面坐标，选框调整不会缩放标注。
先开始长截图，再对拼接结果标注；已有标注时不会静默丢弃标注进入长截图。
放大镜显示进入框选时的屏幕像素、物理坐标和颜色：C 复制颜色文本，Shift 切换 RGB/HEX。
C 不会复制截图；截图复制使用工具栏“完成”。快捷键占用时 C 的失败提示显示在放大镜中。
取消按钮或 Esc 放弃本次截图；若此前主动按 C 复制了颜色，取消不会恢复原剪贴板。

## 长截图

- 蓝框决定完整输出范围；绿色框决定实际滚动、采集和拼接的区域。
- 点击“长截图”后才选择滚动目标。只有一个相交窗口时默认选中；多个窗口时点击高亮目标或选择列表标题。
- 默认绿色范围是蓝框与目标内容区的交集。点“范围”可重新拖动框选，或点击面板尝试识别滚动容器，超时后可手选。“窗口”按钮用于重新选择目标，多候选时显示。
- 绿色框内可拖动移动、边缘可缩放。蓝绿边线重合时优先调整蓝框；调整蓝框后重新校验目标并裁切绿色范围，过小则禁用开始。界面要求绿色范围至少 32×80 逻辑像素。
- 点“开始”后仅定位鼠标一次，随后不抢鼠标。移出绿色区域暂停，回到区域且命中目标窗口后继续。
- Q、工具栏“完成”或点击蓝框之外停止并进入编辑。Esc 或取消按钮放弃本次截图、保留上一张。
- Q 只在采集期间注册，退出采集后释放；注册失败会提示改用鼠标。目标关闭、移动、失去焦点或拼接不可靠时停止，保留已确认内容。

只拼接绿色区域；蓝框其他内容来自激活目标前的底图，只保留一次。
绿色区域新增高度插在其原底边处，两侧填白，原底边以下内容整体下移。
采集期间框大小锁定；不会恢复目标原来的滚动位置。

## 编辑与快捷键

| 阶段 | 操作 | 行为 |
|---|---|---|
| 自动预选 | Tab | 自动／手工切换；确认选区后不占用 |
| 自动预选 | 滚轮 | 上选父级、下选子级；手选层级保持到移出该区域 |
| 自动预选 | C / Shift | 复制颜色文本 / 切换 RGB、HEX |
| 长截图采集 | Q | 停止并进入编辑 |
| 框选／采集 | Esc | 放弃当前截图 |
| 编辑 | 滚轮 | 缩放预览，不改变导出像素 |
| 编辑 | 空格拖动 | 临时平移；选择模式可直接拖动画布 |
| 编辑 | Ctrl+Z / Ctrl+Y | 撤销 / 重做 |
| 编辑 | Ctrl+S / Ctrl+C | 保存 PNG / 复制图片 |
| 编辑 | Esc | 收起编辑器，不主动修改剪贴板 |

普通截图在原位直接标注；长图或托盘查看上一张时使用可缩放画布，支持裁剪、矩形、箭头、文字和矩形马赛克。
马赛克以约 12 个原始像素为一块，与预览缩放无关；可撤销但不能拖走，避免露出原图。
长图画布的普通标注可移动，文字可双击修改。普通截图完成时保存合成结果到上一张，不保留其独立标注图元。
“100%”查看原尺寸，“适应”查看全图。“完成”复制合成结果并返回托盘，保存使用原子写入。
托盘“继续编辑上一张”恢复当前图片与标注；成功截图会替换上一张，退出后不保留历史，请提前保存。
`LongShot.exe --edit 图片路径` 可独立编辑，关闭即退出。

托盘“设置”提供截图快捷键预设和禁用选项，冲突时保留原设置。
“操作说明”和“关于”是独立弹窗。W/A/S/D、Ctrl+A、R、F1 等路线图功能尚未实现。

## 识别策略与限制

- 原生窗口提供基础候选；UIA 原始元素树、MSAA 命中检测、像素边界三路后台并行，每路最多一个调用。
- 像素候选使用进入截图时的底图，检查局部连通底色、填充率及四边对比，适用于底色较均匀的卡片和按钮；不会自动读取截图后出现的悬停效果。
- 16ms 定时采样，不增加候选等待或重试延时。MSAA 与 UIA 的嵌套候选共同参与筛选，不能用大容器挡住另一接口的小按钮；无控件候选时使用像素回退。同一位置允许继续向内缩小，不允许迟到结果放大或横跳；移动后重新识别。UIA 按钮保留整个按钮，不继续钻入内部装饰图标。
- 三路任务独立收取与更新，各路最多一个在途调用；鼠标移动只更新待查询位置，不丢弃整轮查询，也不等待最慢策略。已完成且仍包含光标的区域可临时复用，空闲策略立即查询最新位置。手工选择后后台结果不改变选框。目标接口卡死只影响该路，不无限创建线程。
- MSAA 同时处理子对象和简单 child ID，补齐父容器供滚轮切换；检查 COM 对象身份避免循环。命中遍历预算 100ms，父层级补全共享总预算 150ms，各最多 60 层。预算只在调用间检查，不能中断单次阻塞 COM 调用。
- 等待时保留旧框，自动框允许继续识别内部小区域，滚轮手选仅在光标停留原位置时锁定层级，移动后立即恢复识别。移动、拖动及手动选择会隔离迟到结果。
- 本轮截图缓存最多 64 个已完成位置，鼠标位置完全相同且窗口边界相同才复用，不跨截图保存。鼠标静止且状态不变时不重复重绘。

这些是实现参数，不能当作实测识别延迟。界面元素是否可识别取决于应用暴露的信息；复杂渐变、纹理、动态布局或窗口变化可能导致漏识别或误识别，可用 Tab 手工框选。

长截图最多 100 个确认帧或 256 MiB 估算采集图像内存，达到限制即保留结果。
支持 DPI 坐标换算及负坐标副屏，各屏实际效果仍待验收。滚动区域建议排除标题栏、滚动条和不需要的固定侧栏。
采集工具栏尽量避开滚动区；支持排除捕获时可浮在其上，否则无空位时隐藏，可用 Q（注册成功时）、框外点击或自动到底结束，Esc 取消。
高权限窗口、受保护内容、视频、动画和复杂粘性布局可能无法可靠采集；连续无变化也可能是目标不响应滚轮，并不必然意味着到底。
当前不含横向拼接、OCR、贴图或安装器，未实现项见路线图。

## 构建与部署

环境：

- Qt：`D:\Qt\Qt5.12.9\5.12.9\msvc2017_64`
- VS 初始化：`C:\Program Files\Microsoft Visual Studio\18\Insiders\VC\Auxiliary\Build\vcvars64.bat`
- CMake 3.16 或更新，NMake，Release x64。

当前要求是**只编译部署，不运行测试或桌面自动化**。以下命令在项目根目录的 cmd 中执行：

```bat
call "C:\Program Files\Microsoft Visual Studio\18\Insiders\VC\Auxiliary\Build\vcvars64.bat"
set "QT_ROOT=D:\Qt\Qt5.12.9\5.12.9\msvc2017_64"
set "PATH=%QT_ROOT%\bin;%PATH%"
cmake -S . -B build -G "NMake Makefiles" -DCMAKE_BUILD_TYPE=Release -DCMAKE_PREFIX_PATH="%QT_ROOT%"
cmake --build build
```

每步成功后再继续。已有构建目录也可使用本机 `build\compile-only.cmd`；该文件在忽略目录内，不属于可移植构建入口。
保存图片并退出旧托盘进程后复制 `build\LongShot.exe` 到 `dist\LongShot.exe`。
如需保留运行中的旧进程，可先将被占用的旧 EXE 重命名备份再复制；不要强杀进程或删除未保存图片。
首次部署或依赖变化后执行：

```bat
if not exist dist mkdir dist
copy /y build\LongShot.exe dist\LongShot.exe
copy /y LICENSE dist\LICENSE
"%QT_ROOT%\bin\windeployqt.exe" --release --no-translations --no-opengl-sw --no-system-d3d-compiler dist\LongShot.exe
```

分发时保留整个 `dist` 目录，缺少 MSVC 运行库时安装相应运行库。构建与部署目录均被忽略。
新版不会替换已经加载到旧进程中的代码，需保存图片后退出旧托盘进程并启动新版。

`build.cmd` 是包含测试的完整流程：编译 → ctest → 部署 → deploymentSmoke/trayLifecycle。
它不符合当前“不运行测试”的要求，请勿用它代替上面的仅编译部署步骤。
